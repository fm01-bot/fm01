**fm01** is a Discord bot built to replace and improve upon its predecessor, *FightMan01 bot*. It's a versatile bot
featuring moderation, utility, and fun commands.

## Want to self-host?

No biggie. We specifically built fm01 to be as straight-forward to be self-hosted as possible.
Check out the detailed guide in [SELF-HOSTING.md](SELF-HOSTING.md).

> [!NOTE]
> We do not provide support for self-hosting anywhere, unless you don't change
> the code and still notice bugs. If you do, open an issue.
